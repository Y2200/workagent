2. 核心原则（禁止违反）
1. Prompt必须独立
禁止：
prompt="xxxx"
代码里面不能出现业务Prompt。
统一：
prompts/
加载。
2. 业务解耦
禁止：
RAG里面写权限。
禁止：
Agent里面操作数据库。
禁止：
Web接口里面调用Milvus。
正确：
API

↓

Service

↓

Repository

↓

Database
