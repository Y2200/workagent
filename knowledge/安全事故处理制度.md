# 安全事故处理制度

1. 发生安全事故必须立即上报。

2. 重大安全事件需要第一时间通知负责人。

3. 禁止隐瞒安全事故。

4. 事故处理完成后需要提交复盘报告。

5. 安全事故纳入风险管理。
