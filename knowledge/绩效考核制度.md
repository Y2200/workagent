# 绩效考核制度

1. 公司每季度进行绩效考核。

2. 考核内容包括：

   - 工作完成情况
   - 工作质量
   - 团队协作

3. 任务延期情况会影响绩效评价。

4. 连续低绩效需要制定改进计划。

5. 绩效结果作为晋升和调薪参考。
